# AnyTLS reliab.1 部署后验收

本记录保留公开可复现的验收方法和当次观察结论。环境、时间和设备状态以现场交接为准。

## 背景与技术决策

- 以 Xray 处理分流，AnyTLS helper 由服务监督器管理。检查停止及重启后是否残留旧 helper。
- 用活动节点与目标节点的 DNS 结果分别检查切换前后的状态。切换失败时保留已工作的路由和解析。
- 核对路由器本地流量豁免规则位于路由器集合拦截之前，避免回环。检查订阅同步未覆盖手动节点。

## 验收方法

1. 在授权的测试环境中记录候选版本、目标架构和计划回滚版本。核对安装文件的清单和哈希。
2. 使用临时测试代理及公开测试目标，验证证书校验、DNS、TCP 和 HTTPS；把目标地址写成占位符，例如 `ROUTER_HOST` 和 `TEST_DOMAIN`。
3. 在固定间隔采样 Xray 与 helper 的进程状态、启动次数、内存、FD 数和连接结果。在本地对照日志，并复查代理切换前后的状态。
4. 在受控测试环境演练失败切换。确认原路由仍可用、没有重复 helper、回滚包可取得。若任一检查失败，将本次验收记为未通过并遵循部署指南。

## 当次观察及限制

当次短窗口内，安装清单、路由规则顺序和通过本地代理的证书校验检查通过，关键进程保持运行。该记录仅覆盖一次部署后的短窗口。整机重启、手机通话、长时间负载和其他机型仍需分别验收。
